# Tactical Card Board Game

A turn-based tactical card and board game developed as a university group project.

## About

This project was created as part of a team software development module. The application is a Java-based tactical card game where players control avatars and units on a board using cards, movement, attacks and mana.

Development was carried out collaboratively using GitHub, feature branches and pull requests.

## Features

- Turn-based gameplay
- Board-based unit movement
- Unit and avatar combat
- Card decks and player hands
- Mana system
- Movement and attack validation
- Turn management
- Death handling
- Win and loss conditions
- Game state management
- Basic AI behaviour
- Interactive game interface

## Technologies

- Java
- Git
- GitHub
- IntelliJ IDEA
